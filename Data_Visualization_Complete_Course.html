Data Visualization Libraries

Python provides several powerful libraries for data visualization. Each has its strengths. Understanding which to use when is an important skill.

💡
"Data is just numbers — until you turn it into a picture." Visualization helps us understand patterns, trends, and insights from data by representing it in graphical form.
With Code vs With Tools
💻 With Code
  • Matplotlib, Seaborn, Plotly
  • Very high flexibility — customize every element
  • Can integrate into apps & ML pipelines
🛠️ With Tools
  • Power BI, Tableau, Google Data Studio
  • Limited to what the tool allows
  • Very tough to integrate with ML pipelines
1. Matplotlib
  • Developed in 2003 by John D. Hunter
  • The foundational plotting library in Python
  • Works well for basic charts: line, bar, histogram
  • Highly customizable — more code required
  • Many other libraries are built on top of it
👉
Best for: Learning fundamentals and creating fully customized plots
Python — Import
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
2. Seaborn
  • Built on top of Matplotlib
  • Designed for statistical data visualization
  • Beautiful default styles and color themes
  • Heatmaps, pair plots, distribution plots — easy
  • Works perfectly with Pandas DataFrames
👉
Best for: Quick, attractive, and statistical visualizations with less code

import matplotlib.pyplot as plt
import seaborn as sns

# Load built-in dataset

df.head()

  • Supports 3D plots, dashboards, real-time data
  • Widely used in business analytics and web apps

Matplotlib

Basics — plot() & Labels

The most fundamental Matplotlib function is plt.plot(x, y) which creates a line graph. You can enhance it with title, axis labels, and more.

Setup — Create the Data Arrays
Python — Setup
import numpy as np
import matplotlib.pyplot as plt

# Create 11 evenly spaced numbers from 0 to 5
x = np.linspace(0, 5, 11)
# array([0. , 0.5, 1. , 1.5, 2. , 2.5, 3. , 3.5, 4. , 4.5, 5. ])

y = x ** 2
# array([ 0.  , 0.25, 1.  , 2.25, 4.  , 6.25, 9.  , 12.25, 16.  , 20.25, 25.  ])
1. Basic Line Plot — plt.plot(x, y)

A line graph connects all the (x, y) points with a continuous line. It shows how y changes as x increases.

Python
plt.plot(x, y)
plt.show()
2. Adding Labels — title, xlabel, ylabel

A chart without labels is incomplete. Always add a title and axis labels so your reader knows what they are looking at.

Python
plt.plot(x, y)

# Give the graph a title
plt.title("Hello")

# Label the x-axis
plt.xlabel("number")

# Label the y-axis
plt.ylabel("square")

plt.show()
🏷️
plt.title()
Graph title at top
↔️
plt.xlabel()
X-axis label below
↕️
plt.ylabel()
Y-axis label on left

Subplots

Subplots let you create multiple plots on one canvas at the same time. You divide the canvas into rows and columns, and each cell gets its own plot.

How subplot() Works

plt.subplot(rows, cols, cell_number) — you specify the grid size and then which cell to draw in. Cell numbers go left to right, top to bottom starting from 1.

Python — Syntax
# plt.subplot(rows, cols, cell_number)
plt.subplot(2, 2, 1)  # 2 rows, 2 cols, cell 1 (top-left)
plt.subplot(2, 2, 2)  # top-right
plt.subplot(2, 2, 3)  # bottom-left
plt.subplot(2, 2, 4)  # bottom-right
Plot in Cell 1 Only
Python
plt.subplot(2, 2, 1)
plt.plot(x, y)    # ← plot goes into cell 1

plt.subplot(2, 2, 2)   # empty
plt.subplot(2, 2, 3)   # empty
plt.subplot(2, 2, 4)   # empty
All 4 Cells With Different Plots
Python
plt.subplot(2, 2, 1)
plt.plot(x, y)          # x vs x²

plt.subplot(2, 2, 2)
plt.plot(x**2, y)        # x² vs x²

plt.subplot(2, 2, 3)
plt.plot(x**2, x**2)    # x² vs x²

plt.subplot(2, 2, 4)
plt.plot(x, y)           # x vs x²
Matplotlib

Object Oriented Way

The Object Oriented (OO) approach gives you full control over the canvas (figure) and axes. This lets you place plots anywhere — even one on top of another.

The Canvas — plt.figure()

In the OO approach, you first create a Figure (the blank canvas/white background). Then you manually add Axes objects onto it and plot on each axes.

Python
# Create blank figure canvas
fig = plt.figure()
fig
# Output: <Figure size 640x480 with 0 Axes>
add_axes() — Place Axes on Canvas

fig.add_axes([left, bottom, width, height]) — all 4 values are between 0 and 1 (proportions of the figure). This is how you precisely position plots on the canvas.

ParameterMeaningExample
left (1st)How far from left edge0.1 = 10% from left
bottom (2nd)How far from bottom0.1 = 10% from bottom
width (3rd)Width of axes area0.8 = 80% wide
height (4th)Height of axes area0.8 = 80% tall
Python — Single Axes
fig = plt.figure()
# Add axes: left=0.1, bottom=0.1, width=0.8, height=0.8
fig.add_axes([0.1, 0.1, 0.8, 0.8])
fig
Two Axes — One Inside Another

This is the key advantage of OO approach — you can place a smaller plot inside a larger plot. Like an inset or zoom window.

Python — Two Overlapping Axes
fig = plt.figure()

# Main (big) axes
axes1 = fig.add_axes([0.1, 0.1, 0.8, 0.8])
axes1.plot(x, y)

# Smaller axes placed inside (inset)
axes2 = fig.add_axes([0.3, 0.4, 0.4, 0.4])
axes2.plot(x, y)
figsize — Control Canvas Size

The default figure size is 6.4 × 4.8 inches. Pass figsize=(width, height) to control it. 12 × 100 = 1200 pixels wide, 8 × 100 = 800 pixels tall.

Python — figsize
# 12 x 100 = 1200px wide, 8 x 100 = 800px tall
fig = plt.figure(figsize=(12, 8))

axes1 = fig.add_axes([0.1, 0.1, 0.4, 0.8])
axes1.plot(x, y)

axes2 = fig.add_axes([0.3, 0.4, 0.4, 0.4])
axes2.plot(x, y)

Types of Plots

Matplotlib supports many plot types beyond the line graph. Each is suited to different kinds of data and questions.

a. Scatter Plot — plt.scatter(x, y)

A scatter plot shows individual data points as dots. Great for showing relationships between two variables without connecting them. Unlike a line plot, there is no connecting line — just dots.

Python — Scatter Plot
x = np.linspace(0, 5, 11)
y = x ** 2

plt.scatter(x, y)
plt.title("Scatter Plot")
plt.xlabel("x")
plt.ylabel("x²")
plt.show()
💡
line plot vs scatter plot: Line plot connects dots with a line — for trends over time. Scatter plot shows only the dots — for correlations between variables.
b. Histogram — plt.hist(data)

A histogram takes a single array of data (not x and y separately) and groups values into bins (ranges). The height of each bar shows how many values fall into that bin. Great for seeing the distribution of data.

Python — Histogram
from random import sample

# Get 100 random numbers between 1 and 999
data = sample(range(1, 1000), 100)

plt.hist(data)
plt.title("Histogram")
plt.show()

# Output array: how many values in each bin
# (array([12., 12., 14., 12., 8., 3., 7., 13., 12., 7.]),
#  array([  4., 102.9, 201.8, ...993.]))
c. Boxplot — plt.boxplot(x)

A box plot (box-and-whisker plot) shows the statistical distribution of a single variable. It uses a box to show Q1, median, Q3 and whiskers for min/max. Takes only one value.

Python — Boxplot
x = np.linspace(0, 5, 11)

plt.boxplot(x)
plt.title("Boxplot")
plt.show()
PartWhat it shows
Bottom of boxQ1 — 25th percentile (lower quartile)
Line inside boxMedian (Q2 — 50th percentile)
Top of boxQ3 — 75th percentile (upper quartile)
WhiskersTypical min and max values
Dots beyond whiskersOutliers — unusually extreme values

Saving Plots & Working with Images

Matplotlib can save plots as files and also read, display, and manipulate actual image files. Seaborn cannot work with images — only Matplotlib can.

5. savefig() — Save Your Plot

plt.savefig("filename.format") automatically saves the current figure to your folder. You can save as PNG, PDF, SVG, JPG, and more.

Python — Save a Plot
fig = plt.figure()
axes = fig.add_axes([0.1, 0.1, 0.8, 0.8])
axes.plot(x, y)

# Save as PNG in current folder
plt.savefig("basicplot.png")
# Creates: basicplot.png in your project folder

# Save as PDF (vector — scalable)
plt.savefig("basicplot.pdf")

# Save with high resolution (300 DPI)
plt.savefig("basicplot.png", dpi=300)
📁
The file is automatically saved in the same folder as your Python/Jupyter file. You'll see it appear in your file explorer (e.g., basicplot.png next to Matplotlib.ipynb).
6. Working with Images

Matplotlib can read image files and display them. When you read an image, it is stored as a NumPy array of pixel values (3D array: height × width × RGB channels).

Python — Read & Show Image
# Import the image sub-module
import matplotlib.image as mpimg

# Read image → returns 3D NumPy array
img = mpimg.imread('image.jpg')
img
# array([[[219, 172,  56],
#         [221, 173,  62], ...]])
# shape: (height, width, 3) — 3 = R, G, B values

# Display the image WITH axis numbers
plt.imshow(img)
plt.show()

# Display WITHOUT axis numbers (cleaner look)
plt.imshow(img)
plt.axis("off")   # removes the tick marks
plt.show()
🖼️
plt.imshow(img) — shows image with x/y axis tick numbers visible around it.
✨
plt.axis("off") — hides the axis ticks for a clean image display.

Seaborn Intro & Setup

Seaborn is built on top of Matplotlib and provides beautiful statistical plots with less code. It works perfectly with Pandas DataFrames and includes built-in datasets to practice on.

Quantitative vs Qualitative Variables

Before choosing a plot type in Seaborn, you must understand your data type. This determines which plot to use.

📊 Quantitative (Numeric)

Variables you cannot categorize — they are measured numbers.

Examples: Age (22, 26, 42), Salary (60k, 90k), Total Bill

🏷️ Qualitative (Categorical)

Variables you can categorize into groups or labels.

Examples: Gender (M/F), Smoker (Yes/No), Day (Mon–Sun)

Seaborn — Distribution

histplot / displot / KDE

Distribution plots show how data is spread across a range of values. They answer: "Where does most of my data cluster? Is it spread out or concentrated?"

1. displot() — Basic Distribution

sns.displot(data) creates a histogram — divides data into bins and counts how many values fall in each bin. The x-axis is the value range, y-axis is the count.

Python
# Basic distribution of total_bill column
sns.displot(df["total_bill"])

# Control number of bins (groups)
sns.displot(df["total_bill"], bins=10)

# Same result with histplot:
sns.histplot(df["total_bill"], bins=10)
KDE — Kernel Density Estimate

📊 A Histogram:

  • Divides data into rigid bins (intervals)
  • Counts how many values fall into each bin
  • Looks like bars — blocky and discrete

〰️ KDE (Kernel Density Estimate):

  • Places a smooth curve on each data point
  • Combines into one smooth continuous line
  • Shows true shape: peaks, spread, skewness
Python — KDE Overlay
# Add KDE smooth curve on top of histogram
sns.displot(df["total_bill"], bins=10, kde=True)
# or equivalently:
sns.histplot(df["total_bill"], bins=10, kde=True)
Two Histograms Side by Side

Use plt.subplot() to place two Seaborn plots side by side on one canvas — compare total_bill and tip distributions:

Python — Two histplots on same canvas
# Left plot: total_bill distribution
plt.subplot(1, 2, 1)
sns.histplot(df["total_bill"], bins=20, kde=True)

# Right plot: tip distribution
plt.subplot(1, 2, 2)
sns.histplot(df["tip"], bins=20, kde=True)
Seaborn — Distribution

Jointplot

Jointplot shows the relationship between two variables AND their individual distributions — all in one view. Instead of drawing 3 separate graphs, you get everything together.

Structure of a Jointplot
🔵

Center Plot

Relationship between x and y (scatter, KDE, regression, or hex)

📊

Top Plot

Distribution of x alone (histogram or KDE)

📊

Right Plot

Distribution of y alone (histogram or KDE)

Python — jointplot()
# Basic scatter jointplot
sns.jointplot(x='total_bill', y='tip', data=df, kind='scatter')

# KDE (smooth density)
sns.jointplot(x='total_bill', y='tip', data=df, kind='kde')

# Regression line
sns.jointplot(x='total_bill', y='tip', data=df, kind='reg')

# Hexagonal bins (for large datasets)
sns.jointplot(x='total_bill', y='tip', data=df, kind='hex')

# 2D histogram
sns.jointplot(x='total_bill', y='tip', data=df, kind='hist')
kind Parameter — 5 Types
kind=What appears in centerBest for
'scatter'Individual dots (default)Small datasets, see every point
'reg'Scatter + regression trend lineChecking linear relationships
'kde'Smooth density contour (no dots)Where points cluster most
'hex'Hexagonal bins (color = density)Large datasets — 1000s of points
'hist'2D histogram gridCount-based frequency view
Seaborn — Distribution

Pairplot & Hue

Pairplot shows the relationships between every pair of numerical variables in your dataset — all at once in a matrix of plots.

How Pairplot Works
📐

Matrix Structure

Each row & column = one variable. Creates n×n grid for n numeric columns.

🔵

Off-diagonal Cells

Scatter plot showing relationship between two different variables.

📊

Diagonal Cells

Distribution (histogram/KDE) of a single variable — where it appears with itself.

Python — pairplot
# Basic pairplot — all numeric columns
sns.pairplot(df)
# Creates: total_bill × tip, total_bill × size, tip × size...
# All combinations in one grid!
hue — Colour-Code by Category

hue splits the data by a categorical column and gives each group a different color. It answers: "How do different groups behave inside the same data?"

Python — pairplot with hue
# Color each point by sex (Male=blue, Female=orange)
sns.pairplot(df, hue='sex')

# Or by smoker status
sns.pairplot(df, hue='smoker')
💡
hue adds a categorical distinction using colors. It tells you not just the overall pattern, but whether two groups (e.g., Male vs Female) behave differently.
Seaborn — Categorical

countplot & barplot

Two of the most commonly used categorical plots. countplot counts how many times each category appears. barplot shows the average of a numeric value per category.

1. countplot — Count Each Category

sns.countplot() simply counts how many rows belong to each category and draws a bar. It does NOT need a y-value — it counts automatically.

Python — countplot
# How many Males and Females in dataset?
sns.countplot(df['sex'])
# or:
sns.countplot(x=df['sex'])

# Add hue: how many Males/Females who smoke vs don't smoke?
sns.countplot(x=df['sex'], hue=df['smoker'])
2. barplot — Category vs Numeric Average

sns.barplot() shows the relationship between a categorical variable and a numerical value. Important: By default it shows the MEAN (average) — NOT the count!

⚠️
Most common student confusion: barplot does NOT show counts by default. It shows the average (mean) of the numerical column for each category. Use countplot for counts.
Python — barplot with estimator
import numpy as np

# Default: mean of total_bill per sex
sns.barplot(x=df['sex'], y=df['total_bill'])
# Male bar height ≈ 20.7 (average bill for males)
# Female bar height ≈ 18.1 (average bill for females)

# Change estimator to SUM
sns.barplot(x=df['sex'], y=df['total_bill'], estimator=np.sum)
# Now shows total bill sum per gender

# Other estimators:
estimator=np.mean    # average (default)
estimator=np.median  # middle value
estimator=np.sum     # total sum
estimator=np.std     # standard deviation
estimator=np.min     # minimum value
estimator=np.max     # maximum value
estimator=len        # count (number of observations)
📏
X-axis → categories (Male/Female, Day, Product)
📐
Y-axis → numeric value; height = mean of that value by default
Seaborn — Categorical

Boxplot

A boxplot (box-and-whisker plot) compactly shows the full statistical distribution of a numeric variable across categories using 5 key numbers.

The 5 Parts of a Boxplot
➖
Median (Q2) The line inside the box — the middle value (50th percentile)
📦
Q1 (25%) → Bottom of box Lower quartile — 25% of data falls below this
📦
Q3 (75%) → Top of box Upper quartile — 75% of data falls below this
📏
IQR = Q3 - Q1 Interquartile Range — the height of the box (middle 50% of data)
↕️
Whiskers Extend to typical min/max values (within 1.5×IQR from box edges)
⚫
Outliers Dots beyond the whiskers — unusually high or low values
Python — boxplot
# Tip amount distribution for each day of the week
sns.boxplot(x='tip', y='day', data=df, palette='rainbow')
# x='tip'   → numerical variable (tip amount)
# y='day'   → categorical variable (Thur, Fri, Sat, Sun)
# palette   → just changes colors (rainbow, Blues, Set2...)
How to Read This Boxplot — Tips by Day
1. Median (center line inside each box)
Saturday & Sunday → slightly higher median tips. Thursday & Friday → slightly lower. → Meaning: weekends tend to have higher tips
2. Spread (size of the box = IQR)
Saturday → widest box → more variation in tips. Friday → tighter box → more consistent tips. → Saturday has both low and very high tips
3. Whiskers (normal range)
Show typical min and max. Sunday extends further → wider range of normal tips.
4. Outliers (circles beyond whiskers)
Saturday → many outliers (some tips near 10!). Thursday → a few outliers. Friday → fewer extreme values. → Big tips mostly happen on weekends
Seaborn — Categorical

Violinplot

A violin plot shows the full distribution shape of data across categories using a smooth density curve. It combines the boxplot's summary with KDE's continuous shape.

How a Violin Plot Works
🎻

Violin Shape

The outline is a mirrored KDE curve — symmetric on both sides.

↔️

Width = Density

Wider parts → more data points there. Narrow parts → fewer data points.

📦

Box Inside

Usually includes median and IQR box inside the violin shape.

💡
Boxplot vs Violinplot: A boxplot summarizes data with 5 numbers and highlights outliers. A violinplot shows the full distribution shape using a density curve — you see where data is dense and where it's sparse.
Python — violinplot
sns.violinplot(x='day', y='total_bill', data=df)
# x='day'        → categorical variable (Thu, Fri, Sat, Sun)
# y='total_bill' → numerical variable (bill amount)
# For each day → draws a violin-shaped distribution

# Add color palette
sns.violinplot(x='day', y='total_bill', data=df, palette='rainbow')

# Split by gender using hue
sns.violinplot(x='day', y='total_bill', data=df, hue='sex')
Seaborn — Categorical

stripplot & swarmplot

Both plots show individual data points for each category. The difference is how overlapping points are handled.

stripplot — Jittered Points

A scatter plot where one axis is categorical. Points are randomly jittered slightly sideways so they don't all stack on top of each other.

  • Each dot = one observation (one row in data)
  • X-axis = category (day, sex, etc.)
  • Y-axis = numerical value
  • Points spread randomly (jitter) to avoid overlap
Python
sns.stripplot(x='day', y='total_bill',
             data=df, palette='rainbow')
swarmplot — Non-overlapping

Similar to stripplot but points are carefully arranged so NO points overlap. Each point preserves its exact y-value while being pushed sideways to avoid collisions.

  • Same as stripplot but no overlapping dots
  • Creates a clearer, more accurate view
  • Looks like a tree or swarm of bees
  • Slow for very large datasets (50k+ points)
Python
sns.swarmplot(x='day', y='total_bill',
              data=df, palette='rainbow')
stripplot vs swarmplot — Quick Comparison
Featurestripplotswarmplot
Overlap handlingRandom jitter (may overlap)No overlapping ✅
Point accuracyApproximate x positionExact y, shifted x
SpeedFasterSlower (large data)
ReadabilityGoodBetter ✅
Best forQuick lookPresentation/analysis

Correlation Explained

Before creating a heatmap, you must understand correlation — how two numerical variables move in relation to each other. This is the foundation of the heatmap.

What is Correlation?

Correlation measures how strongly two numerical variables are related. The most common measure is the Pearson correlation coefficient, which always falls between -1 and +1.

+1
Positive Correlation
As one variable increases, the other also increases
0
No Correlation
No consistent relationship between the two variables
-1
Negative Correlation
As one increases, the other decreases
Simple Example — Understanding the 3 Types

Let's use a simple dataset to see all 3 types of correlation:

🔺 C vs A — Positive Correlation As A increases (1→5), C increases (100→550)
🔁 B vs C — Negative Correlation As B decreases, C increases — also negative

Seaborn — Matrix

Heatmap

A heatmap visualizes a grid of numbers (like a correlation matrix) using colors — making it easy to instantly spot strong relationships and patterns.

What a Heatmap Shows
🟥

Each Cell = A Value

For correlation matrices, each cell shows the Pearson correlation between two variables.

🎨

Color = Magnitude

Bright/warm = high value (near +1). Dark/cool = low value (near 0 or -1).

⚡

Instant Insights

Spot strong relationships, patterns, and symmetry at a glance — no reading numbers.

Creating a Heatmap — Tips Dataset
Python — Full Heatmap Workflow
import seaborn as sns
import matplotlib.pyplot as plt

# Load dataset
tips = sns.load_dataset('tips')

# Step 1: Select numeric columns only
tipscorr = tips[["total_bill", 'tip', 'size']]

# Step 2: Compute Pearson correlation matrix
corr_matrix = tipscorr.corr()

# Step 3: Plot the heatmap

Heatmap with Flights Dataset
Python — Flights Heatmap
# Load flights dataset: year, month, passengers
flights = sns.load_dataset('flights')

# Pivot: rows=months, columns=years, values=passengers
flights_pivot = flights.pivot(index='month',
                               columns='year',
                               values='passengers')

# Draw heatmap with value annotations
sns.heatmap(flights_pivot, annot=True, fmt='d', cmap='YlOrRd')
plt.title("Monthly Passengers by Year")
plt.show()

# annot=True  → show numbers inside each cell
# fmt='d'     → format numbers as integers
# cmap        → color scheme (YlOrRd, Blues, coolwarm...)
ParameterWhat it doesExample
annot=TrueShow numbers inside each cellShows 0.67 in correlation cells
fmt='d'Format numbers (d=integer, .2f=2 decimals)Shows 112 instead of 112.0
cmap='YlOrRd'Color schemeYellow→Orange→Red for low→high
